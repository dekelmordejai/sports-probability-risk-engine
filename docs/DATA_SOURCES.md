# Fuentes y procedencia

Los ejemplos incluidos son generados por `src/demo_data.py`; los nombres de equipos sirven como etiquetas y los marcadores, cuotas y estadísticas son inventados. No se distribuyen datasets de proveedores.

| Fuente o herramienta | Uso en el código | Documentación |
|---|---|---|
| Football-Data | Resultados y estadísticas de fútbol; cuotas según columnas disponibles | https://www.football-data.co.uk/data.php |
| nflverse | Calendarios y play-by-play NFL | https://github.com/nflverse/nfldata y https://github.com/nflverse/nflverse-data |
| nba_api | Adaptador de estadísticas NBA | https://github.com/swar/nba_api |
| The Odds API | Eventos, cuotas y resultados | https://the-odds-api.com/liveapi/guides/v4/ |
| Open-Meteo | Consulta opcional de clima de estadio | https://open-meteo.com/en/docs |
| SciPy | Optimización y distribuciones | https://docs.scipy.org/doc/scipy/ |
| scikit-learn | Calibración y métricas | https://scikit-learn.org/stable/ |
| Notion | Adaptador opcional de fuentes de datos | https://developers.notion.com/docs/upgrade-guide-2025-09-03 |

Quien descargue datos reales debe comprobar sus términos de uso, atribución, cobertura y derecho de redistribución. El acceso técnico desde un adaptador no concede derechos sobre los datos. Las URLs y respuestas pueden cambiar; las pruebas públicas usan respuestas simuladas y no acreditan disponibilidad actual de servicios externos.
